## How contribution is verified
- Every commit is made under the author's own GitHub account (no shared logins).
- Every feature is built on its own branch: `feature/<module-name>-<name>`.
- Every merge into `main` goes through a Pull Request, reviewed by at least one other member.
- GitHub → repo → **Insights → Contributors** shows commits, additions/deletions per person over time — this is the objective record for grading.
